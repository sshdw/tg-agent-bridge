# ТЗ — TG Agent Bridge (v0.1, на утверждение)

## 1. Общее
Telegram-бот на Node 20 + TypeScript strict + grammy + SQLite. Один бот — много ИИ-агентов через `IAgentProvider`. Scope v0.1 — текст, без голоса/картинок.

## 2. Функциональные требования
- FR-1 `/start` отвечает <2с, показывает активного агента.
- FR-2 `/ask <текст>` → задача активному агенту, ответ в тот же чат. Стриминг: редактирование сообщения каждые ~1с.
- FR-3 `/code <задача>` → то же, но с пометкой `mode: code` (провайдер может добавить системный префикс).
- FR-4 `/agent <id>` переключает провайдера сессии. Неизвестный id → список доступных.
- FR-5 `/model <name>` сохраняет модель в сессии, проксирует провайдеру. Пустой → сброс.
- FR-6 `/status` — текущая задача + очередь чата.
- FR-7 `/cancel` — убивает running-задачу чата (SIGTERM subprocess / AbortController HTTP).
- FR-8 Очередь: 1 running на чат, остальные pending в SQLite. После `done/error/cancel` — следующая.
- FR-9 Whitelist: `ALLOWED_CHAT_IDS` непуст в проде; чужой → игнор без ответа.
- FR-10 Нарезка: ответы >4000 символов режутся на несколько сообщений, код в ``` блоках.

## 3. Нефункциональные
- NFR-1 Запуск: `npm i && cp .env.example .env && npm run dev` — бот отвечает `/start`.
- NFR-2 `npx tsc --noEmit` чистый, eslint чистый.
- NFR-3 Таймаут задачи дефолт 15 мин (`TASK_TIMEOUT_MS`), настраивается.
- NFR-4 Логи без секретов: токены, ключи, промпты целиком в лог не пишутся (только первые 120 символов в debug).
- NFR-5 Падение провайдера не роняет бота; ошибка → `E_AGENT_FAILED` в чат.
- NFR-6 Docker: `docker build . && docker run --env-file .env` работает.

## 4. Приёмка (smoke)
1. `npm run dev`, в ТГ `/start` → ответ с именем агента.
2. `/ask 2+2` на `mock` → ответ.
3. Переключить `/agent mock`, `/code напиши hello` → ответ кусками/стримом.
4. `/cancel` во время длинной задачи → `cancelled`.
5. Убить CLI (если opencode установлен) → бот жив, в чат `E_AGENT_FAILED`.

## 5. Вне scope v0.1
Голос, картинки, inline-кнопки approve, клонирование репо по URL, мультимодальность, вебхук-режим, многопользовательские группы с ролями. Это v0.2 — добавляем по твоим ответам на 10 вопросов из README.
